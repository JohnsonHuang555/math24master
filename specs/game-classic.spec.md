# 經典 24 點遊戲核心規格書

## 遊戲目標

使用手牌中的 **4 張數字牌**，搭配四則運算符號（+、-、×、÷）與括號，組成一個計算結果等於 **24** 的算式，即可出牌得分。

---

## 牌庫規格

### 牌值範圍
- 固定為 **1 ~ 13**（共 13 種數值）

### 牌庫模式

| 模式 | 說明 |
|------|------|
| `standard`（標準）| 每個數值各 N 張，依玩家人數決定 N |
| `random`（隨機）| 隨機從 1-13 中產生指定總張數的牌庫 |

> 多人遊戲預設使用 standard 模式，可在建立房間時選擇。

---

## 手牌規則

- 每位玩家初始發 **4 張**手牌
- 手牌上限為 **4 張**（`MAX_CARD_COUNT = 4`）
- 每回合開始時抽 1 張牌
- 出牌成功後，所選牌從手牌移除，手牌剩餘張數 ≤ 4

---

## 回合流程

```
1. 輪到玩家 → 自動抽 1 張牌（若手牌 < 4）
2. 玩家從手牌選擇 1~4 張數字牌
3. 玩家從符號列選擇運算符號（+、-、×、÷）和括號
4. 點擊「出牌」→ 伺服器驗算
5a. 驗算 = 24：出牌成功，計算得分，換下一位玩家
5b. 驗算 ≠ 24：出牌失敗，回到步驟 2（手牌不變）
6. 玩家可隨時選擇「跳過」：棄置一張手牌，換下一位玩家
```

---

## 算式驗算

- 使用 **mathjs** 函式庫計算算式結果
- 結果必須等於 `24`（浮點數容差：`Math.abs(result - 24) < 0.001`）
- 括號必須平衡（左右括號數量相等）
- 算式中數字牌的使用數量：**1 ~ 4 張**（`MAX_FORMULAS_NUMBER_COUNT = 4`）

---

## 跳過機制

- 玩家可選擇跳過當前回合
- 跳過時必須**棄置一張手牌**（DiscardCard）
- 多人模式：跳過後換下一位玩家
- 單人經典模式：跳過記入 `classicTotalSkips` 統計

---

## 倒數計時

- 房間設定中可設定每回合秒數限制（`remainSeconds`）
- 設為 `null` 代表無時限
- 計時由伺服器管理（`timerMap`）
- 時間到自動強制換下一位玩家（等同跳過）

---

## 最後回合

- 牌庫耗盡時，進入**最後一圈**
- 所有玩家依序完成最後一回合
- 最後一圈起始玩家記錄於 `rummyFinalRoundStartOrder`（拉密通用欄位，經典模式同樣適用）
- 最後一圈所有玩家完成後，遊戲結束

---

## 勝負判定

- 所有玩家完成最後一圈後，比較**累計總分**
- 分數最高者獲勝
- 同分時以玩家順序判定（先達到者優先）

---

## Socket 事件對應

| 動作 | 事件 |
|------|------|
| 選擇牌/符號 | `SelectCard` |
| 撤回選擇 | `BackCard` |
| 重選 | `ReselectCard` |
| 出牌 | `PlayCard` |
| 抽牌 | `DrawCard` |
| 棄牌（跳過）| `DiscardCard` / `SkipHand` |
| 出牌結果回傳 | `PlayCardResponse` |
| 房間狀態更新 | `RoomUpdate` |
| 遊戲結束 | `GameOver` |
