# Advanced Operator 僅套用於單一操作數，不支援巢狀括號

Quick Math 的 Advanced Mode 新增平方、階乘、根號等 Advanced Operator 時，考慮過允許其套用在任意子運算結果上（例如 `(3+2)²`），但這需要在題目生成器（`lib/quick-math-generator.ts`）引入運算式樹與括號優先順序處理，大幅增加生成邏輯複雜度，也會讓心算負擔跳躍過大。決定 Advanced Operator 只套用在建構過程中的單一原始操作數上（例如 `3² + 5`），維持算式仍是「一路計算下去」的線性結構，可以沿用現有左到右建構＋prefix 驗證的生成架構。

## Considered Options

- 允許巢狀括號表達式：表達力更完整，但生成器需大改，心算難度也可能過陡
- 僅套用單一原始操作數（採用）：實作成本低、心算負擔可控；未來若真的需要支援巢狀，屆時再開新 ADR 覆寫這個決定
