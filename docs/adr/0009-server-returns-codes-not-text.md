# Server 與遊戲邏輯只輸出代碼與參數，不輸出顯示文字

支援多國語系之前，Socket 伺服器直接回傳中文錯誤訊息（如 `error: '房間不存在'`），`lib/`、`stores/` 的遊戲邏輯裡也寫著技能名稱、成就名稱等顯示文字。考慮過讓 client 連線時告訴 server 自己的語系、由 server 翻譯，但同一個房間裡可能有不同語言的玩家，server 還得為每個人分別翻譯廣播訊息。決定改成：`server/`、`lib/`、`stores/` 只輸出代碼（如 `ROOM_NOT_FOUND`）或 id 加參數，所有顯示文字一律由 UI 層透過 message key 翻譯。錯誤代碼定義成 enum，翻譯檔用 `Record<ErrorCode, string>`，少翻一個就編譯失敗。

## Consequences

- 系統廣播訊息（如「某某加入房間」）同樣改成代碼加參數，每位玩家看到自己的語言。
- 玩家輸入的內容（房間名稱、暱稱、聊天）不翻譯。
- 英文的技能名稱、成就名稱要重新取名，不直譯中文成語。
