# 消消樂模式牌局採用反向構造生成，而非隨機發牌

**Status**: accepted

消消樂模式規定「只有 16 張牌全部消除（全清）才計入排行榜」。若沿用經典模式「均勻洗牌、隨機發牌」的邏輯，大多數牌局在數學上可能根本不存在能全清的解法，玩家再怎麼會玩都上不了榜，破壞排行榜的意義。

因此改採**反向構造**：先隨機決定一組分組計畫（每組 2~4 張、各組總和恰為 16 張、每組都能用加減乘除湊出 24），再把所有牌打散排列成 4×4 牌面。這樣保證每一局在生成當下就至少存在一種可全清的解法；玩家中途卡關（見 `CONTEXT.md` 的「卡關」）是消除順序上的失誤，不是牌局本身無解。

**連帶決定**：為了讓反向構造的生成演算法可行，消消樂模式的牌局**不**沿用經典模式「每個數字全域最多出現 2 次」的重複限制——同時滿足「分組湊 24」與「全域重複次數上限」兩個約束，會讓生成演算法明顯複雜、且容易需要重試。消消樂模式僅限制牌值落在 1~13 範圍內，重複次數不設上限。

## Considered Options

- **完全隨機、不做可解性保證**：實作最簡單，但多數牌局可能無法全清，排行榜參與率會很低。
- **抽牌後跑 solver 驗證、不過就重抽**：需要對 16 張牌做「分組完全消除」的可解性搜尋，相較「單一序列合併成一個值」的 `canMake24` 複雜度高得多，重試次數與效能都不可控。
- **反向構造（採用）**：生成階段就保證解存在，且不需要在生成後再做昂貴的可解性搜尋。
