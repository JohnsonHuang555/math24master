## 1. 簡介

### 1.1 產品

24點大師 (Math24 Master) 是一款數學益智遊戲：用數字牌搭配 `+ − × ÷` 與括號，組出結果等於 24 的算式。有多個單人模式、多人連線對戰、每日挑戰與兩個衍生小遊戲，並有全球排行榜。

玩家以手機為主（支援「加到主畫面」當 App 使用），單局短、重複遊玩，節奏偏「通勤時解幾題」。

### 1.2 改版目標

1. 建立一套更乾淨、一致的視覺語言，取代目前頁面之間風格不一的狀況（有的頁面用設計系統，有的仍是早期樣式）
2. **手機體驗是這次的設計重點**：所有遊戲畫面在 360–430px 寬度下要單手可玩、不需捲動就能完成一手牌的操作
3. 補齊遊戲回饋的「手感」：湊出 24、加分、結算等關鍵時刻要有清楚、一致的回饋

### 1.3 不在範圍內

- 不改遊戲規則、計分方式、路由結構與流程順序
- 不新增功能（若設計上認為需要，請放在提案的「建議」中，不要直接畫進主稿）

### 1.4 建議產出順序

請分三批產出，每批完成後再進行下一批：

| 批次 | 內容 | 對應章節 |
|---|---|---|
| 第一批 | Design tokens（色彩、字體、間距、圓角、陰影、動態）與基礎元件 | §2、§3、§4 |
| 第二批 | 外框頁：共用版面、首頁、單人模式選單、多人大廳、排行榜、404 | §5、§6 |
| 第三批 | 各遊戲畫面與所有狀態、modal、關鍵動態時刻 | §7、§8、§9 |

遊戲畫面是這個產品的核心，也最複雜，請不要為了趕完整份而把第三批做淺。

## 2. 設計原則與限制

### 2.1 視覺調性

**乾淨、極簡的益智 App**（參考 NYT Games 的資訊清晰度、留白與字體驅動），**帶一點桌遊卡牌的實體觸感**。

- 資訊清楚優先於裝飾：玩家在小螢幕上解數學題，畫面上的每個元素都要有存在理由
- 個性主要來自「卡牌」：牌面要像拿得起來的實體卡，按下去有回饋
- 不要電競風、不要過多漸層與光暈、不要插畫堆疊

### 2.2 鎖定項目（不可更動）

| 項目 | 說明 |
|---|---|
| 產品名稱與 logo | zh-TW 為「24點大師」，其他語系一律「Math24 Master」。logo 檔沿用 `/public/logo.webp` |
| 卡牌的實體隱喻 | 牌面有圓角、明顯邊框、底部實色陰影（厚度感），按下時下沉、陰影縮短。可以調整比例、圓角大小、陰影顏色，但隱喻本身要保留 |
| 背景圖 | 全站底圖（mint 底 + 右上 teal、左下 amber 的放射漸層；dark 為 zinc-950 底）與 Memphis 幾何紋理 `/public/b2.webp`（首頁 hero、多人頁以約 20% 透明度疊加）。沿用現有的圖、漸層與使用位置，元件與版面要能放在這組背景上 |
| 牌桌模式的牌色 | 四種顏色：紅、青、黃、黑，**每種顏色搭配一個固定形狀**（讓色弱玩家能分辨）。這牽涉遊戲規則（牌組須同色或全異色），顏色數量與「色＋形」的配對不可改；色值可微調，但四色之間必須清楚可分辨 |

### 2.3 建議保留（可以提替代方案）

| 項目 | 現況 | 說明 |
|---|---|---|
| 主色 | teal `hsl(175 84% 32%)`（dark：`hsl(173 66% 45%)`） | 品牌辨識度來源。若提替代方案，請同時提供保留 teal 的版本 |
| 數字字體 | Baloo 2（圓潤、粗體，用於數字牌、分數、大標題） | 數字是畫面主角，字體要讓 1、7、4 等數字一眼分辨。可提替代方案 |

### 2.4 開放重做

- 次要色、語意色的分配方式
- 內文字體（目前 Noto Sans TC；見 §2.7 的語系字型規則）
- 所有元件的外觀、所有頁面的版面

### 2.5 裝置

- **手機優先**。主要設計寬度 375px，需在 360px 驗證不破版，430px 驗證不鬆散
- 桌機是手機版的合理延伸，不需要另做一套體驗；但以下畫面請另外設計桌機佈局，因為同時要呈現的資訊較多：
  - 多人房間的等待大廳（玩家列表、房間設定、聊天室）
  - 多人遊戲中（對手資訊、公共區、自己的手牌）
  - 牌桌模式遊戲中（計分板、桌面、組裝列、手牌）
  - 排行榜
- 遊戲畫面在手機上：主要操作（數字牌、符號、送出）必須在拇指可及的下半部；**完成一手牌的操作不需要捲動**
- 需處理 iOS 安全區域（瀏海、底部 home indicator），PWA 模式下沒有瀏覽器網址列

### 2.6 無障礙（硬性要求）

- 文字與背景對比達 **WCAG AA**（一般文字 4.5:1、大字 3:1），light 與 dark 都要符合
- 觸控目標至少 **44 × 44 px**（包含符號按鈕、chips 上的可點擊元素、modal 關閉鈕）
- 支援 `prefers-reduced-motion`：每個動態都要有減少動態的替代方案（見 §9）
- **顏色不能是唯一的資訊來源**：對錯、選取狀態、牌色、倒數警示等，都要搭配圖示、形狀、文字或位置變化
- 桌機建議：遊戲操作可只用鍵盤完成（數字鍵選牌、符號鍵輸入運算子、Enter 送出、Backspace 倒退），焦點狀態清楚可見

### 2.7 多語系

支援 zh-TW（預設）、en、zh-CN。

- **以英文文案的長度驗證版面**。英文通常比中文長 1.5–2 倍；按鈕、chips、tab、HUD 標籤在英文下不能截斷、不能換行到破版
- 按鈕文字不換行；空間不足時版面要能調整（例如 icon + 短字、或改直排），不要縮小字級到難以閱讀
- 字型依語系載入：zh-TW 用 Noto Sans TC、zh-CN 用 Noto Sans SC、en 不載入 CJK 字型。設計時請確認選用的字體在三種情況下都成立
- 語系切換器要出現在首頁頂部，以及其他頁面中合理可及的位置
- 玩家輸入的內容（暱稱、房間名稱、聊天）不翻譯，且可能混合各種語言、長度不一，需處理截斷
- 數字、日期依語系格式化

本文件的範例文案會同時列出 zh-TW 與 en。目前部分遊戲頁面尚未翻譯成英文，這些頁面的 en 文案請以「中文字數 × 2 個英文字元」估算長度。

### 2.8 圖示與文案

- **介面中不使用 emoji**（按鈕、提示、toast、chips、分享文字都一樣）。需要視覺強調時使用 `lucide-react` 圖示
- 目前站上仍有 emoji 與符號字元（`✓ ✗ ⏰ 🔥 🔍 🔄 ✎` 等，見 §10），新設計請全部改用圖示
- 元件庫基礎為 Radix UI（shadcn/ui 模式）與 Tailwind，動態使用 Framer Motion，設計上的互動請以這些能實作的範圍為準

### 2.9 深色模式

light 與 dark 兩套都要設計，每個元件、每個畫面都要有 dark 樣式。跟隨系統設定。

## 3. 基礎設計：現況參考

以下是目前的 tokens，供理解現況，不是限制（鎖定與保留項目見 §2.2、§2.3）。

### 3.1 色彩

| 角色 | 現況 | 用途 |
|---|---|---|
| Primary | teal（見 §2.3） | 主 CTA、選中的牌、強調數字、正確回饋 |

- 模式之間要不要用顏色區分，若要，用哪幾色
- 評級（S / A / B / C）、名次獎牌（金銀銅）的配色

## 4. 元件清單

請為以下元件設計所有狀態（default / hover / pressed / focus / disabled / 以及列出的特殊狀態），並提供 light 與 dark。

### 4.1 遊戲元件

| 元件 | 狀態與說明 |
|---|---|
| **數字牌** | 一般、選中、hover 選中（點擊會取消選取）、disabled（非自己回合）、已消除（消消樂）。尺寸至少要有：手牌大尺寸、4×4 牌面中尺寸、桌面牌組小尺寸、紀錄列表迷你尺寸 |
| **牌桌模式數字牌** | 數字牌加上牌色與形狀標記（紅、青、黃、黑各配一形狀）；Joker 未宣告（顯示 J）、Joker 已宣告（顯示宣告的數值與顏色，且要看得出是 Joker） |
| **運算符號按鈕** | `+ − × ÷ ( )`；心算快答進階另有 `x² x! √x`（顯示在題目中，非按鈕）。一列 6 顆在 360px 寬不可折行 |
| **算式列** | 顯示玩家目前組出的算式（數字與符號以 chip 呈現），右側即時顯示計算結果：空白（顯示提示文字）、結果非 24、結果為 24、算式不完整 |
| **操作列** | 清除、倒退一步、跳過（挑戰模式，需顯示下次跳過扣幾秒）、離開，加上主 CTA（出牌 / 確認 / 確認消除 / 放上桌面 / 提交） |
| **HUD** | 得分（數字滾動）、模式名稱、牌庫剩餘張數、關卡數、題號進度、計時器 |
| **計時器** | 大數字倒數（mm:ss）+ 進度條；一般、低時限（≤ 60 秒，需非顏色的警示）、暫停 |
| **加分飄字** | 「+N 分！」 |
| **玩家卡** | 頭像、暱稱、分數、手牌數；狀態：輪到他、最後一輪、作答中、鎖定中（含倒數）、已準備、房主、電腦玩家（含難度）、「你」 |
| **搶答鈕** | 可搶答、等待中、鎖定中（顯示剩餘秒數）、已被他人搶到 |

## 6. 外框頁

### 6.1 首頁 `/`

**目的**：讓第一次來的玩家 3 秒內懂這是什麼遊戲，讓回訪玩家一點就進到想玩的模式。

**層級（由上而下，依重要性）**：

1. **Hero**：一句話說明玩法、示意牌面（目前是 6、4、3、2 四張扇形牌加算式 `6 × 4 × (3 − 2) = 24`），以及兩個 CTA：
   - 主 CTA「立即開始」→ 單人模式選單 `/single-play`（四種單人模式在那裡選，見 §6.2）
   - 次 CTA「多人對戰」→ 多人大廳 `/multiple-play`
2. **更多遊戲**：每日挑戰（排第一，可顯示今日是否已完成、連續天數）、心算快答、猜數字
3. **玩法三步驟**：抽牌 → 湊 24 → 得分
4. **頁尾**

首頁的入口維持現狀，不在首頁直接放四種單人模式（單人模式目前沒有各自的網址，這次改版不處理路由）。

**其他元素**：公告橫幅（頂部，可關閉）、頂部列（§5.1）。

**文案**：

| 元素 | zh-TW | en |
|---|---|---|

| 副標 | 利用 4 張數字牌，透過加、減、乘、除與括號，組合出等於 24 的算式 | Use 4 number cards with +, −, ×, ÷ and parentheses to build an equation that equals 24 |

| 多人 | 多人對戰 | Multiplayer |

### 6.2 單人模式選單 `/single-play`

**目的**：選擇單人模式。點選後直接進入該模式（目前網址不變，模式是頁面內的狀態）。

每張模式卡內容：

| 模式 | 名稱 zh-TW / en | 一句話 | 特色 chips | 個人最佳顯示 |
|---|---|---|---|---|
| 經典 | 經典模式 / Classic | 牌值 1–13 · 累積最高分 | 解題獲得分數、尋找最佳解答、牌庫抽完即遊戲結束 | `N 分` |
| 挑戰 | 挑戰模式 / Challenge | 倒數 5 分鐘 · 無限關卡 | 答對加秒數、跳過會懲罰、挑戰通過最多關卡數 | `第 N 關` |

### 6.3 多人大廳 `/multiple-play`

## 7. 遊戲畫面

每個遊戲畫面的通用結構：**開始畫面 → 遊戲中 → 結算畫面**（部分模式會跳過開始畫面直接進入遊戲）。

### 7.0 單人模式共用：結算後的排名與登入

- 結算卡上有「第 N 名 · 查看排行榜」按鈕，點擊開啟精簡 modal：我的名次 + 前 3 名 + 「查看完整排行榜」
- 未登入且有得分時，結算 1 秒後跳出「同步至排行榜」modal（見 §8）
- 新紀錄時顯示「新紀錄！」標記；否則顯示「個人最高：N 分」

### 7.1 經典模式 (Classic)

**規則摘要**：每手 4 張牌（牌值 1–13），用全部 4 張組出 24 即可出牌得分。可以跳過換牌（不計分）。牌庫抽完即結束。

**計分**：`+` `−` 各 1 分、`×` 2 分、`÷` 3 分；用 2 個乘號 +1、2 個除號 +1；拿滿這手的理論最高分為「完美手」，額外 +1。

**遊戲中要呈現的資訊**：

- HUD：得分（數字滾動）、模式名稱、牌庫剩餘張數、最後一輪警示（「最後一輪！」）
- 4 張手牌
- 算式列 + 即時計算結果
- 符號列 `+ − × ÷ ( )`
- 操作：清除、倒退一步、離開、主 CTA「出牌」、次要文字按鈕「跳過換牌」（最後一輪時變成「結算」）
- 工具：規則

**狀態與回饋**：

| 狀態 | 呈現 |
|---|---|
| 尚未選牌 | 算式列顯示「點選數字和符號組成算式...」 |
| 組算式中 | 即時結果：= N（非 24 為錯誤樣式，等於 24 為正確樣式；不可只用顏色區分） |
| 沒用完 4 張就出牌 | toast「必須使用全部 4 張手牌」 |
| 沒選任何牌就按出牌 | 確認 dialog「未作答，確定要跳過？」 |
| 出牌成功 | 依序播放每個符號的得分動畫（每個約 250ms）→ 顯示加成（「2 張乘 +1」「2 張除 +1」）→ 全螢幕「+N 分！」→ 這手結算回饋顯示約 3 秒：「完美手，拿滿 N 分 · 額外 +1」或「本手最高 N 分 · 拿下 M 分」 |
| 出牌動畫期間 | 所有操作 disabled |
| 最後一輪 | HUD 顯示「最後一輪！」 |
| 點離開 | 確認 dialog「確定要離開？離開後本局進度將不會保存。」（繼續遊戲 / 離開） |

**結算畫面**：

- 標題「遊戲結束」、最終得分（大數字）
- 解法評級 S / A / B / C、解法效率 %（總分 ÷ 理論最高分）、完美手次數
- 新紀錄或個人最高
- 「查看作答紀錄」（開啟作答紀錄 modal，見 §8）
- 「分享成績」（產生圖卡；產生中顯示「圖卡產生中...」）
- 排名按鈕（§7.0）
- 「返回選單」、「再來一局」

### 7.2 挑戰模式 (Challenge)

**規則摘要**：倒數 5 分鐘、無限關卡，每題 4 張牌。答對加時（第 1 關 +60 秒，每關遞減 3 秒，最少 +15 秒）；跳過扣時，同一關內第 1 次 −15 秒、第 2 次 −30 秒、第 3 次起 −60 秒，答對後重置。時間到或提前結算即結束，以答對題數（關卡）排名。

**遊戲中要呈現的資訊**：

- HUD：模式名稱、規則、提前結算
- **大計時器**（mm:ss）+ 進度條（以 5 分鐘為滿格）；加時 / 扣時飄字
- 第 N 關、總分
- 4 張牌、算式列、符號列
- 操作：清除、跳過（tooltip 顯示「跳過此題（−N 秒）」）、離開、主 CTA「確認」

**狀態與回饋**：

| 狀態 | 呈現 |
|---|---|
| 剩餘 ≤ 60 秒 | 低時限警示（目前是紅色 + 閃爍；需加上非顏色的提示） |
| 答對 | 加時飄字、進入下一關 |
| 跳過 | 扣時飄字；沒作答直接按確認時跳確認 dialog，說明會扣幾秒 |
| 提前結算 | 確認 dialog「確定要提前結算？提前結算後遊戲將立即結束，計分以目前關卡為準。」 |

**開始畫面**：模式名稱、「倒數 5 分鐘 · 無限關卡」「答對加時遞減 · 連續跳過懲罰加重」、個人最佳（第 N 關 / N 分）、返回、開始遊戲。

**結算畫面**：標題依原因為「時間到！」或「提前結算！」、最終關卡、總分、新紀錄或個人最佳、排名按鈕、「返回選單」、「再挑戰」。

### 7.3 消消樂模式 (Matching Mode)

**規則摘要**：開局 16 張牌排成 4×4 的牌局 (Board)，每次任選 2–4 張湊出 24 即可消除。目標是全清 (Full Clear)，沒有時間限制。只有全清才計分上榜；如果剩下的牌怎麼選都湊不出 24，系統判定卡關 (Stuck) 並結束該局。

**遊戲中要呈現的資訊**：

- HUD：得分、模式名稱、剩餘張數、規則
- **4×4 牌面**（這是手機版面的最大挑戰：16 張牌 + 算式列 + 符號列 + 操作列要在一個畫面內放下）
- 算式列（提示「點選 2~4 張牌和符號組成算式...」）
- 符號列
- 操作：清除、倒退一步、離開、主 CTA「確認消除」、次要「重新開局」

**狀態與回饋**：

| 狀態 | 呈現 |
|---|---|
| 牌被選取 | 選中樣式 |
| 消除成功 | 被消除的牌從牌面上移除（需要設計消除動畫，以及空格的呈現方式）、全螢幕「+N 分！」 |
| 重新開局 | 確認 dialog「要放棄目前牌局嗎？將會開始新的一局，目前的進度不會保留。」（繼續這局 / 重新開局） |
| 離開 | 確認 dialog（同經典） |

**結算畫面（兩種）**：

| 結果 | 內容 |
|---|---|
| 全清 | 「全清！」、最終得分、新紀錄或個人最佳、分享成績、排名按鈕、返回選單、再來一局 |
| 卡關 | 「卡關了」、「剩下 N 張牌怎麼選都湊不出 24」、本局得分（標示「未計入排行榜」）、返回選單、再來一局 |

### 7.4 牌桌模式 (Tabletop Mode)，Beta

這是最複雜的模式，請特別花時間在手機版的資訊層級。

**規則摘要**：改編自桌遊拉密。玩家與 2 個電腦對手輪流行動，起始手牌 10 張，**出牌後不補牌**。

- 每回合可以：把手牌組成一組牌組 (Set) 放上共用的桌面 (Table)，並且可以拆開、重組桌上既有的牌組；或是沒有牌可出時抽 1 張
- 牌組：3–5 張數字牌搭配運算符號與括號，結果等於 24；顏色必須「全部同色」或「全部不同色」（5 張只能同色）
- 每回合只能完成一組牌組 (Completing a Set)，這回合打出的手牌必須全部落在同一組
- 回合結束時，桌上每一組都必須成立，拆出來的散牌必須全部放回牌組
- Joker：打出時宣告它代表的數值與顏色；所在牌組被拆開時變回未宣告
- 有人出完手牌就結束：先出完 +10 分，其他人手上每張數字牌 −1、每張 Joker −5
- 牌庫抽完後進入最後一圈 (Final Round)
- 三種難度：簡單（電腦只會接牌）、普通（電腦會拆一組重組）、困難（電腦會同時拆兩組）

**遊戲中要呈現的資訊**：

| 區域 | 內容 |
|---|---|
| 頂部工具 | 離開、紀錄（出牌紀錄）、規則 |
| 計分板 | 第 N 圈 / 最後一圈、牌庫剩 N 張；三位玩家各自的分數、手牌 N 張、狀態（思考中 / 出牌中）；電腦行動時的「略過動畫」 |
| 桌面 | N 組牌組，每組顯示算式（小牌面 + 符號）、該組分數、「拆開」按鈕；本回合變動的牌組要高亮；空桌提示「桌面還是空的，用手牌組出第一組吧」 |
| 散牌區 | 拆開牌組後還沒用掉的牌；提示「散牌區：要全部放回牌組才能結束回合」 |
| 組裝列 | 正在組的算式；提示「點手牌或散牌，加上符號組成算式」；結果等於 24 時顯示「等於 24 · 預估 N 分」；符號 `+ − × ÷ ( )` 單行、退格、清空、主 CTA「放上桌面」 |
| 手牌 | 標題「手牌 N 張」，依顏色再依數值排序、Joker 排最後；**固定一行，放不下時橫向滑動**，兩側漸層提示可滑動 |
| 底部操作列（固定在畫面底部） | 「還原桌面」、「抽牌」、「結束回合」，加上狀態說明：電腦回合時「電腦出牌中」；可以結束時「可以結束回合了」；不能結束時顯示原因；還沒行動時「完成一組牌組，或抽 1 張牌」 |

**狀態與回饋**：

| 狀態 | 呈現 |
|---|---|
| 電腦回合 | 手牌、組裝列 disabled；計分板顯示哪個電腦在思考；桌面上電腦變動的牌組高亮 |
| 點 Joker | 跳出「宣告 Joker」dialog（選數值、選顏色） |
| 組裝錯誤 | 即時提示原因：「數字牌之間要有運算符號」「一組最多 5 張牌」「左括號前面要有運算符號」「右括號沒有對應的左括號」「運算符號前面要先有數字」等 |
| 不能結束回合 | 底部顯示原因（例如散牌區還有牌、桌上有牌組不成立） |
| 離開 | 確認 dialog「確定要離開？離開後本局不計分，進度也不會保存。」 |

**開始畫面**：模式名稱、「改編自拉密 · 和 2 個電腦搶先出完手牌」、「每回合湊一組 24，可以拆開桌上的算式重新組合」、難度選擇（簡單 / 普通 / 困難，各附一句說明）、查看規則、返回、開始遊戲。另有 Beta 提示（排行榜重置日期）。

**結算畫面**：「你贏了！」或「第 N 名」、你的總分、新紀錄或個人最佳、三位玩家的分數明細（牌組分 + 出完加分 − 剩牌扣分 = 總分）、排名按鈕、返回選單、再來一局。最終分數 ≤ 0 時不上榜。

### 7.5 每日挑戰 (Daily Challenge)

**規則摘要**：每天 3 題，全球同題。每日挑戰日以台灣時間 00:00 為分界，與玩家所在時區無關。每題用全部 4 張牌組出 24；答錯會被罰分。完成後記錄連續天數。

**畫面**：

| 階段 | 內容 |
|---|---|
| 開始 | 「每日挑戰」、「每天 3 題，累積你的連續挑戰紀錄」、「開始挑戰」 |
| 遊戲中 | 第 N / 3 題、4 張牌、算式列（「組合你的算式」）、符號列、倒退、清除、出牌 |
| 答錯 | 罰分提示：「算式有誤」或「結果是 N，不等於 24」 |
| 每題完成 | toast「第 N 題完成！」 |
| 完成 | 本日總分（共 3 題）、連續天數、分享預覽 +「複製分享」、各題解法面板（第 N 題（數字）→ 可展開解法）、「繼續練習」、「挑戰朋友」 |
| 今天已完成再進來 | 直接顯示完成畫面 |

**注意**：

- 這個頁面目前沒有套用設計系統（樣式較陽春），請以其他遊戲畫面的標準重做
- 分享文字目前有 emoji（「🔥 連續 N 天」），需改為純文字
- 「今天」的概念對海外玩家可能與當地日期不同，畫面上可以考慮標示下一題的倒數時間

### 7.6 心算快答 (Quick Math)

**規則摘要**：10 題連續快答，每題是一道算式，心算後輸入答案。難度逐題提升。答錯 +3 秒罰時，可以重試。全部答完即結束，以總花費時間排名。兩種難度：

- 初階 / Basic：純四則運算
- 進階 / Advanced：混入平方 `x²`、階乘 `x!`、根號 `√x`

**畫面**：

| 階段 | 內容 |
|---|---|
| 模式選擇 | 「選擇模式」，兩張模式卡（初階：純四則運算 · 熟悉基本節奏；進階：混入平方、階乘、根號 · 更燒腦），各附個人最佳 |
| 開始 | 「心算快答」、「10 題連續快答 · 全球排行榜」、規則說明、個人最佳、排行榜連結、開始挑戰、切換模式 |
| 遊戲中 | 計時、第 N / 10 題、累計罰時、題目卡、答案顯示框（「輸入答案」）、**數字鍵盤**（含清除、送出） |
| 答錯 | 「+3 秒」飄字、答案框錯誤回饋 |
| 結算 | 「挑戰完成」、10 題完成時間、含答錯罰時 +N 秒 或「全程零失誤！」、個人最佳紀錄標記、排名按鈕、再玩一次 |

**手機重點**：數字鍵盤要像原生計算機一樣好按，題目與答案框要在鍵盤上方完整可見。

### 7.7 猜數字 (Guess the Number)

**規則摘要**：謎底是 10–99 的兩位數，最多 10 回合。每回合從手牌選一張線索牌，系統回答「是」或「否」，再輸入猜測。猜對立即獲勝。

- 線索牌（共 16 種，每張有名稱與問題），例如：半壁江山（謎底 ≥ 55？）、陰陽雙極（謎底是奇數？）、黃金質數（謎底是質數？）、高低雷達（謎底 > 上一次猜的？）
- 特殊牌（每局各限用一次）：透視鏡（顯示目前所有可能的數字 5 秒）、全面革新（重新抽一組手牌）
- 評分依回合數分五級：1 回合、2–3、4–6、7–10、未猜中

**畫面**：

| 區域 | 內容 |
|---|---|
| 標題列 | 「猜數字」、規則、筆記 |
| 謎題展示區 | 謎底說明（10–99）、剩 N 個未猜；使用透視鏡時顯示剩餘可能的數字（剩餘 / 排除 / 已猜三種狀態） |
| 進度 | 第 N / 10 回合、已排除 N 個 |
| 歷史 chip 列 | 每回合的線索結果與猜過的數字 |
| 線索結果 banner | 「是」或「否」；特殊牌提示 |
| 選牌區 | 手牌（線索牌 + 特殊牌）；提示文字依狀態：「選擇一張牌使用」「已選牌，請輸入猜測數字」等 |
| 猜測輸入 | 「輸入 10-99」、送出；重複猜時提示「你已猜過 N，可繼續送出」 |
| 下一回合 | 「下一回合」 |

**附屬介面**：

- 選牌確認 dialog「使用這張牌？」
- **筆記抽屜**：10–99 的數字格，玩家可以手動標記排除；支援「點擊選取」與「滑動連選」兩種模式、清除全部
- **規則抽屜**：遊戲目標、每回合流程、特殊牌、線索牌一覽、評分標準

### 7.8 多人房間 `/multiple-play/[roomId]`

**連線狀態**：

| 狀態 | 內容 |
|---|---|
| 連線中 | 「連線中...」「如果等待時間過長，請嘗試重新整理頁面」、回首頁、回房間列表 |

| 遊戲中斷 | 「遊戲中斷」「由於 {玩家} 離開，遊戲已中斷」、回房間列表、關閉視窗 |

#### 7.8.1 等待大廳

**桌機**：左欄玩家列表；右欄房間設定 + 聊天室。**手機**：需要重新設計層級（三塊資訊要排出優先順序）。

**玩家列表**：

- 標題「玩家 (N)」
- 每位玩家：頭像、暱稱、狀態（房主、已準備、電腦玩家與難度）
- 房主可以踢除其他玩家（確認 dialog「是否踢除玩家？」）
- 房主在搶答模式下可以「加入電腦玩家」（選難度：簡單 / 普通 / 困難）
- 主要按鈕：房主為「開始遊戲」（有人未準備時會失敗並顯示「尚有玩家未準備」）；其他人為「準備遊戲 / 取消準備」
- 開始前全體倒數：系統訊息「遊戲將在 N 秒開始」，可被取消（「遊戲開始倒數已取消」）

**房間設定**（房主可編輯，其他人唯讀）：

| 設定 | 選項 |

| 玩家人數 | N 人 |
| 傳統：牌庫類型 | 標準（1–10 各 N 張）/ 全部隨機 |
| 傳統：每回合秒數 | N 秒 / 無限時 |
| 搶答：牌面範圍、獲勝條件（先獲得 N 分）、作答秒數、失敗扣分（不扣分 / 扣 1–3 分）、鎖定秒數、每回合時間（不限時 / N 秒）、逾時扣分、連續答對加分（不加分 / 連勝數 × 1 / × 2）、最低分數（不設定 / 0 分） | 每項附說明 tooltip |

#### 7.8.2 傳統對戰（多人）

**規則摘要**：玩家輪流，每人手牌 4 張，輪到自己時用手牌組出 24 出牌得分，或抽牌 / 換牌；手牌超過上限時必須丟 1 張。每回合有時間限制（可設定無限時）。牌庫耗盡進入最後一輪。

**畫面要呈現**：

- 對手玩家：暱稱、得分、持牌數、「換他」（輪到他）、「最後」（最後輪到的玩家）
- 回合剩餘時間
- 自己的資訊：你的回合、牌庫剩餘 N 張、終回標記、當前得分
- 手牌、算式區（提示「點擊手牌組合出答案為 24 的算式」）、即時結果、加成提示
- 操作：出牌、跳過 / 換牌（最後一輪為結算）、清除、倒退
- 工具：遊戲規則、離開房間

**狀態**：輪到你（toast「你的回合」）、不是你的回合（操作 disabled）、需要棄牌（toast「請點選 1 張牌丟棄」，手牌進入棄牌選擇模式）、出牌動畫中。

**注意**：這個畫面是最早期的樣式，與其他畫面差距最大，請完整重做。

**結算**：遊戲結束 modal（見 §8）。

#### 7.8.3 搶答模式 (Buzzer)

**規則摘要**：每回合顯示 4 張公共牌（所有玩家共用）。未被鎖定的玩家可以按「搶答」取得作答資格，在作答時間內用 4 張公共牌組出 24。答對得分（可有連勝加分）並進入下一回合；答錯或超時扣分並鎖定一段時間。玩家可以投票認為此題無解。先達到獲勝分數的人獲勝。

**畫面要呈現**：

| 區域 | 內容 |
|---|---|
| 頂部工具列 | 第 N 回合、遊戲規則、離開房間、回合計時器（可暫停）、無解投票（「我覺得此題無解」/ 手機「無解？」、已投票、N / 總人數 票） |
| 公共牌 | 4 張 |
| 作答狀態列 | 「{玩家} 作答中」 |
| 作答面板 | 作答者：可操作（選數字與符號、清除、提交）；旁觀者：唯讀，看得到作答者正在組的算式 |
| 搶答鈕 | 「搶答！」/ 等待中... / 鎖定中 Ns |
| 玩家清單 | 玩家卡：作答中、鎖定中、（你） |

**回饋**：

| 事件 | 呈現 |
|---|---|
| 回合開始 | 全螢幕倒數 overlay |
| 答對 | 「答對！+N 分（+M 連勝）」 |
| 答錯 | 「答錯，−N 分」 |

## 9. 關鍵動態時刻

這些時刻決定了遊戲的手感。每個時刻請設計動態，並提供 `prefers-reduced-motion` 下的替代方案（通常是：去掉位移與縮放，只保留淡入淡出或直接顯示，但資訊不能少）。

| 時刻 | 觸發 | 要傳達的資訊 | reduced-motion 替代 |
|---|---|---|---|
| **選牌** | 點擊數字牌 | 這張牌已加入算式 | 直接切換選中樣式 |
| **算式等於 24** | 即時結果剛好 = 24 | 「可以出牌了」，引導按主 CTA | 結果區的靜態正確樣式 + 圖示 |
| **出牌成功** | 送出正確算式 | 每個符號各得幾分、有哪些加成、總共加幾分 | 一次顯示得分明細，不逐一播放 |
| **完美手** | 拿滿這手最高分 | 拿滿了，額外 +1 | 靜態標記 |
| **算式錯誤** | 送出不等於 24 的算式 | 錯在哪（結果是多少） | 錯誤訊息，不晃動 |
| **消除**（消消樂） | 消除成功 | 哪些牌被消除、牌面剩多少 | 牌直接消失 |
| **加時 / 扣時**（挑戰、快答） | 答對、跳過、答錯 | 時間變化的秒數 | 靜態文字，停留稍久 |
| **低時限** | 剩餘 ≤ 60 秒 | 時間快到了 | 靜態警示樣式 + 圖示，不閃爍 |
| **卡關**（消消樂） | 系統偵測無解 | 為什麼結束、這局不計分 | 直接進入結算 |
| **電腦行動**（牌桌） | 電腦回合 | 電腦改動了哪些牌組；可略過動畫 | 直接高亮變動的牌組 |
| **回合交替**（多人、牌桌） | 輪到你 | 現在可以操作了 | 靜態提示 |
| **搶答成功 / 失敗** | 搶答、答對、答錯、鎖定 | 誰搶到、結果、分數變化 | 靜態通知 |
| **回合倒數**（搶答） | 每回合開始 | 3、2、1，公共牌即將出現 | 數字直接切換 |
| **遊戲結束** | 結算 | 成績、評級、是否新紀錄 | 直接顯示結算卡 |
| **新紀錄** | 超過個人最佳 | 慶祝 | 靜態標記 |
| **成就解鎖** | 任何時候 | 解鎖了什麼 | toast 直接出現 |
| **每日挑戰完成** | 第 3 題完成 | 本日總分、連續天數 | 直接顯示 |

## 10. 待確認事項

以下是我在讀程式碼時整理出的問題，需要產品端決定，或是請 Claude Design 在提案中提出建議。

1. **色相規則需要重新定義**。現行設計系統規定只有四個色相，但心算快答用 violet、評級 B 用 blue。新色彩系統要明確規範模式色與評級色
2. **emoji 與符號字元**。以下位置需要改用圖示：算式即時結果的 `✓ ✗`、搶答回饋的 `✓ ✗ ⏰`、每日挑戰分享文字的 `🔥`、猜數字規則的 `🔍 🔄 🎲 🧠 👍 💪 😤`、猜數字筆記的 `✎`
3. **規則呈現方式不一致**。猜數字用抽屜，其他模式用 dialog
4. **頁面風格不一致**。每日挑戰、多人傳統對戰、猜數字仍是早期樣式
5. **成就入口**。桌機版隱藏、手機版顯示
6. **「再來一局」的流程**。經典模式目前是重新整理整個頁面，體驗上有閃白
7. **模式選單點擊延遲**。點模式卡後等 0.5 秒才進入（為了播放按壓動畫），可以考慮用轉場取代等待
8. **音效開關**。元件已存在但停用，是否要在新設計中啟用
